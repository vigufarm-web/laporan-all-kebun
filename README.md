# Laporan All Kebun — PT VIGU FARM INDONESIA

Portal tautan Dashboard Kebun, Daily Mandor, Data Kebun, Peta Kebun, Payroll dan Gudang. Situs statis tanpa database atau kredensial.

GitHub Pages: gunakan branch `main`, folder `/ (root)`. Untuk mengubah tautan, edit daftar `apps` di `index.html`. Hak akses tetap mengikuti aplikasi tujuan.
